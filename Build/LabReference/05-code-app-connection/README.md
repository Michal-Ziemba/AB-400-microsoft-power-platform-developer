# Lab 05 reference: Display profile data through a Power Platform connection in a code app

This folder is a completed reference for instructors and lab testers, not a file the learner downloads.

It shows the finished state of `src/components/ProfileCard.tsx` after the exercise's
"Bind the profile component to the connection" task, plus illustrative stand-ins for the
TypeScript files the Power Apps CLI generates:

- `src/generated/models/Office365UsersModel.ts`
- `src/generated/services/Office365UsersService.ts`

The real versions of those two files are generated by `pa app add data-source` against a live,
code-apps-enabled environment, so they aren't identical to the ones here (and aren't meant to
be copied into a learner's project). This reference also omits `power.config.json`, because
that file is tied to one tenant's environment ID and is never checked into source control.

To confirm this reference still compiles, run:

```bash
npm install
npm run build
```
